# Komentář k zákonu České národní rady č. 592/1992 Sb., o pojistném na veřejné zdravotní pojištění

Otevřený komentář k zákonu o pojistném na veřejné zdravotní pojištění (PojZP) — § po §: doslovné znění, výklad, kazuistika, protiargumenty a praktický závěr; sazba a vyměřovací základy zaměstnanců, OSVČ, osob bez zdanitelných příjmů a státu, zálohy, penále, přerozdělování pojistného mezi zdravotními pojišťovnami, kontrola placení, přehledy, pokuty a přílohy o přerozdělování.

Konsolidované znění: dokument e-Sbírky `SB-1992-00592_2026-01-01`.
